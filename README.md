## 🚀 Удосконалення стратегії мобільного робота (`8_6.py` та `8_6_improved.py`)

У межах лабораторної роботи досліджено та кардинально покращено стратегію керування автономним роботом $s_3$ у 2D фізичному середовищі **PyMunk / NodeBox**:

### 1. Канонічне рівняння Белмана (Temporal Difference Q-Learning)
Замість простого лінійного накопичення балів без врахування майбутніх наслідків, у проект впроваджено класичне рівняння часової різниці:
$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \cdot \left[ r_{t+1} + \gamma \max_{a} Q(s_{t+1}, a) - Q(s_t, a_t) \right]$$
де швидкість навчання $\alpha = 0.15$, коефіцієнт дисконтування $\gamma = 0.90$.

### 2. $\varepsilon$-жадібна політика з експоненційним затуханням ($\varepsilon$-decay)
Для збалансованого дослідження (Exploration) та експлуатації накопиченого досвіду (Exploitation):
$$\varepsilon_{t+1} = \max(\varepsilon_{\min}, \; \varepsilon_t \cdot d), \quad \varepsilon_0 = 1.0, \; \varepsilon_{\min} = 0.05, \; d = 0.998$$

### 3. Простір станів $\mathcal{S}$ (дискретизація технічного зору)
* **Стан 0 (Вільний рух):** відсутність об'єктів у секторі огляду робота ($R_{\text{sens}} < 110$, $|\Delta\theta| < 0.5$ рад).
* **Стан 1 (Ціль у секторі):** корисний об'єкт $s_1$ зафіксовано сенсором.
* **Стан 2 (Небезпека у секторі):** антиоб'єкт $s_2$ зафіксовано сенсором.
* **Стан 3 (Критичне наближення до стіни):** відстань від центру арени $R > 155$ пікселів.

### 4. Простір дій $\mathcal{A}$ (цільові кінематичні маневри)
* **Дія 0 (Прямо):** збереження крейсерського курсу зі стабільною швидкістю.
* **Дія 1 (Наведення на $s_1$):** векторний доворот безпосередньо на азимут корисної цілі.
* **Дія 2 (Ухилення від $s_2$):** маневр відвороту по нормалі до вектора небезпеки ($\theta_{s_2} + \pi/2$).
* **Дія 3 (Розворот до центру):** поворот у безпечну зону арени для запобігання зіткненням із периметром.
